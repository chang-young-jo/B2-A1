# 나만의 프롬프트 관리 프로그램

Python과 Git 기초 학습을 위해 제작한 콘솔 기반 프롬프트 관리 프로그램입니다.

자주 사용하는 AI 프롬프트를 등록하고 목록 조회, 카테고리별 조회, 검색, 상세 보기, 즐겨찾기 등의 기능을 사용할 수 있습니다.

## 개발 환경

- Python 3.13
- Visual Studio Code
- Git
- GitHub

## 실행 방법

1. 프로젝트를 다운로드하거나 Git 저장소를 Clone합니다.
2. VS Code에서 프로젝트 폴더를 엽니다.
3. 터미널에서 아래 명령어를 실행합니다.

```bash
python main.py
```

## 주요 기능

### 1. 프롬프트 추가
- 새로운 프롬프트를 등록할 수 있습니다.
- 제목, 내용, 카테고리를 입력합니다.
- 새로 등록한 프롬프트의 즐겨찾기 기본값은 False입니다.

### 2. 프롬프트 목록
- 등록된 모든 프롬프트를 번호와 함께 확인할 수 있습니다.
- 제목과 카테고리를 표시합니다.
- 즐겨찾기 프롬프트에는 ⭐가 표시됩니다.

### 3. 카테고리별 조회
- 원하는 카테고리를 선택하여 해당 카테고리의 프롬프트만 확인할 수 있습니다.

### 4. 프롬프트 검색
- 검색어를 입력하여 프롬프트를 검색할 수 있습니다.
- 제목 또는 내용에 검색어가 포함된 프롬프트를 출력합니다.

### 5. 프롬프트 상세 보기
- 프롬프트 번호를 입력하여 상세 내용을 확인할 수 있습니다.
- 제목, 카테고리, 즐겨찾기 여부, 전체 내용을 표시합니다.

### 6. 즐겨찾기 관리
- 프롬프트 번호를 이용하여 즐겨찾기를 추가하거나 해제할 수 있습니다.

### 7. 즐겨찾기 목록
- 즐겨찾기로 등록된 프롬프트만 모아서 확인할 수 있습니다.

### 0. 종료
- 프로그램을 종료합니다.

## 프롬프트 카테고리

프로그램에서 사용하는 카테고리는 다음과 같습니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 기본 프롬프트

프로그램 시작 시 3개의 기본 프롬프트가 등록되어 있습니다.

1. 블로그 글 작성 도우미
2. 제품 썸네일 생성
3. IT 컨설턴트

## Git 학습 내용

프로젝트를 진행하면서 Git을 이용하여 코드의 변경 이력을 관리했습니다.

- Git 저장소 초기화
- 기능 단위 Commit
- GitHub 원격 저장소 Push
- 별도 Branch에서 프롬프트 목록 기능 개발
- `checkout`을 이용한 Branch 이동
- `merge`를 이용하여 기능 Branch를 `main` Branch에 병합
- GitHub를 이용한 원격 저장소 관리
